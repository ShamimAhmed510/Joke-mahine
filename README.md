# The Joke Machine

A tiny single-page app styled like a ticket dispenser. Press **Get Joke** and it prints a random joke, then works out a one-line "twist" explaining why it's funny.

## What it does

- Fetches a random joke from the [icanhazdadjoke](https://icanhazdadjoke.com/) public API
- Shows a loading state while the joke prints
- Shows a second loading state while the twist is worked out
- Shows a clear error state if the joke API fails
- Displays the joke on top, with a short "THE TWIST" explanation underneath

## Files

- `joke-machine.html` — the whole app (HTML, CSS, JS) in one file. No build step, no dependencies.

## Running it locally

Just open `joke-machine.html` in a browser. That's it.

## Deploying

Any static host works, since it's a single HTML file:

- **GitHub Pages** — rename the file to `index.html`, push to a repo, enable Pages in the repo settings.
- **Netlify Drop** — go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag the file in. Live URL in seconds, no account needed.
- **Vercel** — `vercel deploy` from a folder containing the file.

## About the "twist" feature

The joke comes from a free public API that needs no key, so that part works anywhere you deploy it.

The **twist explanation** is generated by calling the Anthropic API directly from the page. That call only works inside the claude.ai artifact environment, where the API key is handled automatically. If you deploy this file standalone (GitHub Pages, Netlify, etc.), that call will fail because there's no key available in the browser.

To make the twist feature work on a standalone deploy, you have two options:
1. Build a small backend (even a single serverless function) that holds your Anthropic API key and proxies the request, so the key is never exposed in the browser.
2. Remove the twist feature and ship just the joke-fetching part, which needs no key at all.

## Known limitations

- No offline support.
- The twist explanation is only as good as the model's read of the joke — occasionally it may restate the punchline rather than explain it.
- No joke history or favorites — each click replaces the previous joke.
